# 🌾 KrishiYukti – AI Powered Smart Farming Assistant

## 📖 Overview

KrishiYukti is an AI-powered AgriTech platform developed for the NUV ISEN TetraThon Hackathon 2026.

The platform assists small-scale farmers by providing intelligent crop advisory, disease detection support, weather-based recommendations, and post-harvest market planning through an easy-to-use multilingual interface.

---

## 🚀 Features

- 🌱 AI-assisted Crop Advisory System
- 📷 Leaf Disease Detection (Prototype)
- 📍 GPS / Pincode Location Detection
- 🌦 Weather-based Farming Recommendations
- 💰 Smart Mandi Price Planner
- 📊 Spoilage Risk Estimation
- 🔊 Voice Assistant Support
- 🌐 Multilingual Interface
- 📱 Farmer-Friendly Responsive UI
